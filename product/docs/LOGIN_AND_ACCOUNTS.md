# 登入與帳號

版本：0.1.0 開發中；適用產品：0.1.0；負責：主作者；外部審查：待整合複審。
來源：需求基線 AD 登入、權限矩陣及使用者詢問登入／新增／修改／改密碼。

| 操作 | 第一版行為 |
|---|---|
| 登入 | 公司 AD 帳號及密碼，透過驗證憑證的 LDAPS 驗證。正式 AD 未驗證。 |
| 新增公司帳號 | 由既有公司 AD 程序辦理；平台不提供 AD 帳號寫入權限。 |
| 建立平台身分 | 符合設定 AD 群組資格的人員首次成功登入時建立，以 objectGUID 識別。 |
| 修改姓名／帳號 | 從 AD 更新，不在平台覆寫目錄資料。 |
| 修改角色 | 正式環境依 AD 群組；案例級操作授權另由有權主管管理。 |
| 啟用／停用平台資格 | 具帳號管理權限者填原因操作，舊登入立即失效；不能停用自己。 |
| 改密碼／忘記密碼 | 依公司 AD 密碼管理程序；平台不儲存 AD 密碼。 |
| 登出 | 撤銷伺服器端登入憑證；舊 Cookie 無法繼續使用。 |

一般同仁無帳號管理入口；呼叫管理 API 也會被拒絕。維護身分不自動取得工作或機密內容。
測試模式使用明確標示的合成人員選單，沒有實際驗證密碼，不能當作 AD 驗收。

本頁範圍說明不代表公司已提供帳號自助服務網址；未提供前不放無效「改密碼」連結。
